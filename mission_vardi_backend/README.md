# Mission Vardi Backend

FastAPI + AWS Lambda + API Gateway + S3 JSON Database

## Run Locally

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Swagger Docs:
http://127.0.0.1:8000/docs

## AWS Lambda Handler

app.main.handler

## AWS Runtime

Python 3.12

## Features

- FastAPI backend
- AWS Lambda ready
- API Gateway compatible
- S3 JSON database
- Pre-signed S3 uploads
- Firebase Auth ready
